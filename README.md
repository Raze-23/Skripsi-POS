## 📌 Tentang Project

Sistem Point of Sale (POS) ini adalah aplikasi berbasis web yang dikembangkan khusus sebagai pemenuhan syarat Tugas Akhir / Skripsi. Aplikasi ini dirancang dengan studi kasus pada **CV. Herbal Attiin** guna mendigitalisasi dan mengoptimalkan proses bisnis yang sebelumnya berjalan secara konvensional. 

Sistem ini memfasilitasi pencatatan transaksi kasir secara *real-time*, manajemen inventaris produk herbal, serta otomatisasi pembuatan laporan penjualan untuk membantu pengambilan keputusan bisnis oleh pihak manajemen.

## Fitur Utama

- 📦 **Manajemen Inventaris:** Pengelolaan (CRUD) data produk, kategori, dan pemantauan ketersediaan stok obat herbal.
- 🛒 **Transaksi Kasir (Point of Sale):** Antarmuka interaktif yang responsif untuk memproses transaksi pelanggan dengan cepat dan efisien.
- 👥 **Role-Based Access Control (RBAC):** Pembatasan hak akses sistem yang terstruktur untuk *Admin*, dan *Kasir*.
- 📊 **Pelaporan & Analitik:** Pembuatan laporan penjualan harian, bulanan, dan tahunan yang dapat diekspor atau dicetak.
- 🧾 **Cetak Struk:** Pencetakan struk bukti transaksi.
